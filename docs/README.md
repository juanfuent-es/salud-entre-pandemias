# Salud entre pandemias

Archivo editorial de seminarios y materiales educativos sobre salud humana, salud animal, alimentación sostenible y bienestar.

Este repositorio reúne transcripciones automáticas, documentos temáticos y versiones resumidas elaboradas a partir de materiales audiovisuales. Su propósito es facilitar la consulta y navegación de contenidos originalmente presentados en formato de video.
